# Kids Speaker Project Requirements

## Overview
Small form factor streaming speaker that plays back content from Spotify, AirPlay, various podcast sources, and internet radio. Primary controls are through native apps on smart devices (phones and iPads). A simple website should also be available to control podcast and internet radio playback. Bluetooth will be used as a control interface for volume and playback.

## Hardware
- **Base**: Raspberry Pi Zero W (version 1)
- **Amp**: IQaudIO Pi-Codec Zero HAT

## Features
- **Streaming Services**:
  - Spotify
  - AirPlay
  - Podcast sources
  - Internet radio
- **Control Interfaces**:
  - Native apps (phones and iPads)
  - Simple website
  - Bluetooth (volume and playback control)

## User Stories
- As a user, I want to stream music from Spotify so that I can listen to my favorite songs.
- As a user, I want to use AirPlay to stream audio from my Apple devices.
- As a user, I want to listen to podcasts so that I can stay informed and entertained.
- As a user, I want to listen to internet radio so that I can discover new music and shows.
- As a user, I want to control the speaker using my phone or iPad so that I can easily manage playback.
- As a user, I want to use a simple website to control the speaker so that I can manage playback from any device.
- As a user, I want to use Bluetooth to control volume and playback so that I can adjust settings without using my phone.

## Technical Requirements
- **Hardware Compatibility**: Ensure compatibility with Raspberry Pi Zero W and IQaudIO Pi-Codec Zero HAT.
- **Software Compatibility**: Ensure compatibility with Spotify, AirPlay, and various podcast and internet radio services.
- **User Interface**: Develop native apps for phones and iPads, and a simple website for controlling the speaker.
- **Bluetooth Integration**: Implement Bluetooth functionality for volume and playback control.

## Future Enhancements
- Voice control integration
- Multi-room audio support
